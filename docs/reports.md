## Test Reports

The following CI test reports are generated and uploaded via GitHub Actions:

### Backend JUnit Reports
- **Workflow**: GitHub Actions CI workflow → `backend` job
- **Tool**: mikepenz/action-junit-report
- **Format**: JUnit XML
- **Retention**: 14 days (GitHub Actions artifact retention policy)
- **Access**: Available in the Actions tab for runs within 14 days

### Frontend Vitest Reports
- **Workflow**: GitHub Actions CI workflow → `frontend` job
- **Format**: JUnit XML (generated via `--reporter=junit`)
- **Retention**: 14 days
- **Access**: Available in the Actions tab for runs within 14 days

### Playwright E2E HTML Reports
- **Workflow**: GitHub Actions CI workflow → `playwright-e2e` job
- **Tool**: upload-pages-artifact
- **Format**: HTML
- **Retention**: 14 days
- **Access**: Available in the Actions tab for runs within 14 days

### Coverage Reports
- **Backend**: JaCoCo coverage report (generated by backend CI job)
- **Frontend**: Vitest coverage report (generated by frontend CI job)
- **Threshold**: 100% for all critical paths

## CI Jobs Overview

Five CI jobs ensure end-to-end protection of capabilities:

| Job | Purpose | Owner |
|-----|---------|-------|
| `traceability` | Ensure traceability of claims to evidence | PO Architect |
| `backend` | Ensure backend stability | PO Architect |
| `frontend` | Ensure frontend stability | PO Architect |
| `playwright-e2e` | Ensure Playwright E2E tests pass | PO Architect |
| `mention-check` | Ensure no @-mentions in GitHub posts | PO Architect |

## Coverage Report

The coverage report drills from each capability down to the individual test that proves it. It includes:

- **Capability → feature → scenario → test** drilldown tables
- **Code coverage** (backend JaCoCo, frontend Vitest)
- **Mutation testing** (PIT) results per class
- **GitHub source links** for every element

[View the coverage report →]({{ site.baseurl }}/coverage/)

## How to Read Reports

1. **Check CI status**: Verify all jobs pass in the repository CI
2. **Run verification scripts**:
   - `node scripts/verify-capabilities.js` - Checks capability matrix
   - `node scripts/check-docs.js` - Checks documentation
3. **Review coverage reports**: Check JaCoCo (backend) and Vitest (frontend) reports
4. **Track @todo items**: Review the capability registry for pending scenarios
